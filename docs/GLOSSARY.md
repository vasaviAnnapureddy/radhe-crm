# Glossary

Plain meanings for every domain and tech word used in this project. New words are added here the first time they appear.

## Real estate words

| Word | Meaning |
|---|---|
| BHK | Bedroom, Hall, Kitchen. "3 BHK" is a home with 3 bedrooms. |
| Carpet area | The floor area you can actually walk on inside the home, in sq ft. |
| Super built-up area (SBA) | Carpet area plus walls plus a share of common areas (lobby, lifts). Price is usually charged on SBA. |
| Price per sq ft (PSF) | The base rate. Home price is roughly SBA x price per sq ft, plus extra charges. |
| PLC (preferred location charge) | Extra amount for a better spot, like a corner unit or a park view. |
| Floor rise charge | Extra amount for higher floors. |
| Facing | The direction the main door or balcony faces (East, West, North, South). East is often preferred. |
| EOI (expression of interest) | A small refundable amount a buyer pays to show serious interest before launch. |
| Booking amount | The first payment that reserves a unit for the buyer. |
| Agreement for sale | The signed contract between buyer and builder with price and possession date. |
| Construction-linked plan (CLP) | A payment plan where the buyer pays in parts, each part due when a construction stage is finished. |
| Demand letter (demand) | The builder's request to the buyer to pay the next part. |
| Registration | Recording the sale with the government, making the buyer the legal owner. |
| Possession | The day the buyer gets the keys. |
| OC (occupancy certificate) | Government approval that the building is safe to live in. |
| Snag | A small defect found at handover, like a cracked tile. |
| JDA (joint development agreement) | A deal where a landowner gives land and the builder builds; they share the units or revenue. |
| RERA | The real estate regulator. Every project has a RERA registration number. |
| Channel partner | A broker firm that brings buyers and earns a commission. |
| Site visit | A buyer's visit to the project or model flat. |
| RM (relationship manager) | The employee who looks after a buyer after booking. |
| NRI | Non-resident Indian, a buyer living abroad. |
| HNI | High net-worth individual, a very wealthy buyer. |
| Slip | How many days a construction milestone is behind its planned date. |
| Collection efficiency | Money collected divided by money demanded, as a percent. |
| Receivables ageing | Unpaid demands grouped by how long they have been overdue (0-30, 31-60, 61-90, 90+ days). |
| Lakh / Crore | Indian number units. 1 lakh (L) = 1,00,000. 1 crore (Cr) = 1,00,00,000. |

## Tech words

| Word | Meaning |
|---|---|
| API | The set of URLs the frontend calls to get data from the backend. |
| ORM | A library (SQLAlchemy) that lets Python code work with database tables as classes. |
| Migration | A versioned script (Alembic) that creates or changes database tables. |
| Seed data | Fake but realistic data loaded into the database for the demo. |
| JWT | A signed token that proves the admin is logged in. |
| httpOnly cookie | A cookie that browser JavaScript cannot read, which keeps the JWT safer. |
| KPI | Key performance indicator, one important number on a card. |
| Quick view | The small card shown when you hover a name, unit, deal or tower. |
| Drawer | A panel that slides in from the right to show details without leaving the page. |
| Proxy / rewrite | A rule that forwards `/api` calls from the frontend's address to the backend. |
